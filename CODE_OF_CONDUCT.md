# Code of Conduct

Gatehouse contributors must make the project safe and useful for all participants.

## Expected conduct

- Be kind, direct, and patient.
- Discuss the work, not the worth of a person.
- Welcome questions and different experience levels.
- Give clear evidence and accept correction.
- Protect private information and security reports.
- Stop behavior when a maintainer says it harms the community.

Harassment, threats, discrimination, sexual attention, personal attacks, deliberate disruption, and publishing private information are not allowed.

## Report a problem

Report conduct problems privately to the repository maintainers through the contact options on their GitHub profiles. Do not open a public issue that exposes a target or reporter. Maintainers will limit access to the report and act as soon as practical.

Maintainers may edit or remove contributions and may warn, suspend, or ban a participant. They will consider the safety of affected people first.

This code applies in Gatehouse project spaces and when a person represents the project in public.
